# ДЕЛО ТЕХ — Отчёт №13: Движение по импорту

Автоматический скрипт для извлечения отчёта с rlisystems.ru/conterra/ с OCR (Tesseract).

## Установка

```bash
# Установка зависимостей
pip install playwright openpyxl pytesseract pillow
playwright install chromium

# Установка Tesseract OCR (Ubuntu/Debian)
sudo apt-get install tesseract-ocr tesseract-ocr-rus
```

## Использование

```bash
python3 extract_report_13_ocr.py --start 20.07.2026 --end 10.08.2026 --output report.xlsx
```

## Параметры

- `--start` — начальная дата (ДД.ММ.ГГГГ)
- `--end` — конечная дата (ДД.ММ.ГГГГ)
- `--output` — имя выходного файла (по умолчанию: report_13_ocr.xlsx)

## Что делает скрипт

1. **Авторизация** — логин через JS-инъекцию (Vaadin 7)
2. **Навигация** — клики по меню "Дополнительные услуги" → "Отчетность по обработке груза"
3. **Открытие отчёта** — двойной клик на "13. Движение по импорту"
4. **Установка дат** — заполнение полей с временем
5. **Генерация** — клик "Показать отчет"
6. **Скриншот** — сохранение полного отчёта
7. **OCR** — распознавание таблицы через Tesseract
8. **Excel** — создание файла с данными

## Результат

- `report.xlsx` — данные отчёта
- `report.png` — скриншот (на всякий случай)
- `report_table.png` — обрезанная таблица
- `report_ocr.txt` — распознанный текст (для отладки)

## Особенности

- **Vaadin 7** блокирует стандартный доступ к DOM, поэтому используется OCR
- **Точность OCR** ~85-90% (зависит от качества отчёта)
- Рекомендуется **проверять результат** по скриншоту
