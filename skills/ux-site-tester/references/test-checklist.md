# Чеклист тестирования UX/UI

## Критерии оценки

- 🔴 **Critical** — Блокирует использование (сломанная форма, битая оплата)
- 🟡 **Major** — Ухудшает UX (медленная загрузка, ошибки в консоли)
- 🟢 **Minor** — Косметические проблемы (опечатки, мелкие сдвиги)

## 1. Навигация
- [ ] Все ссылки работают (200 OK)
- [ ] Меню отображается корректно
- [ ] Хлебные крошки присутствуют
- [ ] Поиск работает
- [ ] Футер с актуальными контактами

## 2. Формы
- [ ] Все поля имеют лейблы
- [ ] Обязательные поля помечены (*)
- [ ] Валидация работает (email, телефон)
- [ ] Сообщения об ошибках понятны
- [ ] Кнопка отправки активна
- [ ] После отправки — страница подтверждения
- [ ] Данные сохраняются в БД

## 3. Email-рассылки
- [ ] Письмо приходит на указанный email
- [ ] Тема письма понятная
- [ ] HTML-форматирование корректное
- [ ] Ссылки в письмах работают
- [ ] Вложения приходят (если заявлены)
- [ ] Письмо не попадает в спам
- [ ] Отправитель корректный (не спам-имя)

## 4. Адаптивность
- [ ] Десктоп (1920x1080) — без горизонтального скролла
- [ ] Планшет (768x1024) — элементы удобны для нажатия
- [ ] Мобильный (375x667) — текст читаем, кнопки крупные
- [ ] Меню адаптируется (бургер на мобильных)
- [ ] Изображения масштабируются

## 5. Производительность
- [ ] Время загрузки < 3 секунд
- [ ] TTFB < 600ms
- [ ] Изображения оптимизированы
- [ ] CSS/JS минифицированы
- [ ] CDN используется

## 6. Контент
- [ ] Текст без орфографических ошибок
- [ ] Шрифты читаемые
- [ ] Контраст текста и фона достаточный (WCAG AA)
- [ ] Изображения релевантны
- [ ] CTA-кнопки заметны

## 7. SEO
- [ ] Title и Description на всех страницах
- [ ] H1 один на страницу
- [ ] Alt-тексты у изображений
- [ ] URL понятные

## 8. Безопасность
- [ ] HTTPS работает
- [ ] Формы отправляются по HTTPS
- [ ] Cookie безопасные

## 9. Доступность
- [ ] ARIA-лейблы на элементах
- [ ] Навигация с клавиатуры
- [ ] Alt-тексты на изображениях
